# **App Name**: FileForge

## Core Features:

- File Uploader: Drag-and-drop interface for uploading photos and videos.
- Custom Filename Input: Text field input to specify the new filename before uploading.
- Server-Side Filename Management: Files are renamed on the server based on the user input.
- Admin File Management: A basic admin interface (accessible via a separate hidden URL) to list uploaded files, allow downloads, renames, and deletions.
- Theme Switcher: Theme toggle for switching between light and dark modes.
- AI Filename Suggestion: AI tool to generate suggested filenames based on the image/video content and textual description.

## Style Guidelines:

- Primary color: A muted blue (#5885AF) to reflect reliability and stability, fitting for file management.
- Background color: For light mode, a very light gray (#F2F4F7); for dark mode, a dark gray (#2B2D31).
- Accent color: A vibrant orange (#E07A5F) for call-to-action buttons and interactive elements, providing a strong contrast.
- Clean and readable sans-serif font for file names and UI elements.
- Simple and recognizable icons for file types and actions (download, rename, delete).
- Clean and efficient layout to quickly parse the contents and focus on task execution
- Subtle transitions and feedback animations during file operations (upload, rename, delete).
