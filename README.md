
# آپلود ویدئو های وردلد آف وارکرفت (Transaction House)

فایل‌فورج یک برنامه تحت وب مدرن است که برای آپلود، مدیریت و سازماندهی فایل‌های تصویری و ویدیویی طراحی شده است. این برنامه از قدرت هوش مصنوعی (Genkit) برای پیشنهاد نام‌های هوشمندانه برای فایل‌های شما بهره می‌برد و تجربه کاربری روان و کارآمدی را ارائه می‌دهد.

## ✨ ویژگی‌های کلیدی

*   **آپلود آسان فایل:** امکان آپلود فایل‌های تصویری و ویدیویی با کشیدن و رها کردن (Drag & Drop) یا انتخاب از طریق مرورگر.
*   **پیشنهاد نام فایل با هوش مصنوعی:** Genkit نام‌های مرتبط و توصیفی بر اساس محتوای فایل و توضیحات شما پیشنهاد می‌دهد.
*   **مدیریت فایل‌ها:** تغییر نام، حذف و پیش‌نمایش فایل‌های آپلود شده.
*   **پیش‌نمایش داخلی:** مشاهده پیش‌نمایش تصاویر و پخش ویدیوها مستقیماً در برنامه.
*   **پنل مدیریت امن:** داشبورد اختصاصی برای مدیر سیستم جهت مدیریت تمامی فایل‌ها با احراز هویت.
*   **تم روشن و تاریک:** قابلیت انتخاب بین تم روشن و تاریک برای راحتی چشم کاربر.
*   **طراحی واکنش‌گرا:** تجربه کاربری یکپارچه در دسکتاپ، تبلت و موبایل.
*   **رابط کاربری مدرن:** استفاده از کامپوننت‌های زیبا و کاربردی ShadCN UI.

## 🛠️ پشته فناوری

*   **فریم‌ورک اصلی:** Next.js 15 (App Router, Server Components, Server Actions)
*   **زبان برنامه‌نویسی:** TypeScript
*   **رابط کاربری:** React 18
*   **استایل‌دهی:** Tailwind CSS
*   **کامپوننت‌ها:** ShadCN UI
*   **هوش مصنوعی:** Genkit (Google AI - Gemini)
*   **اعتبارسنجی داده‌ها:** Zod
*   **مدیریت فرم‌ها:** React Hook Form
*   **آیکون‌ها:** Lucide React
*   **استقرار:** Firebase App Hosting (پیکربندی شده)

## 🚀 راه‌اندازی در محیط توسعه محلی (Local Development)

برای اجرای فایل‌فورج روی سیستم محلی خود، مراحل زیر را دنبال کنید:

### پیش‌نیازها

*   [Node.js](https://nodejs.org/) (نسخه 18.x یا بالاتر پیشنهاد می‌شود)
*   [npm](https://www.npmjs.com/get-npm) (معمولاً همراه Node.js نصب می‌شود) یا [yarn](https://classic.yarnpkg.com/en/docs/install)

### مراحل نصب و اجرا

1.  **کلون کردن ریپازیتوری (یا دانلود فایل‌ها):**
    ```bash
    git clone <URL_ریپازیتوری_شما>
    cd fileforge-project 
    ```
    (اگر URL ریپازیتوری را ندارید و فایل‌ها را به صورت مستقیم دریافت کرده‌اید، به مرحله بعد بروید)

2.  **نصب وابستگی‌ها:**
    ```bash
    npm install
    # یا اگر از yarn استفاده می‌کنید:
    # yarn install
    ```

3.  **تنظیم متغیرهای محیطی:**
    یک فایل با نام `.env.local` در ریشه پروژه خود ایجاد کنید و محتوای زیر را در آن قرار دهید:

    ```env
    # رمز عبور برای ورود به پنل مدیریت (/taupload)
    ADMIN_PASSWORD=yoursecurepassword

    # کلید API گوگل برای استفاده از Genkit و مدل‌های Gemini
    # این کلید را می‌توانید از Google AI Studio دریافت کنید.
    # یا از طریق gcloud auth application-default login احراز هویت کنید.
    GOOGLE_API_KEY=your_google_ai_api_key 
    ```
    *   **مهم:** `yoursecurepassword` را با یک رمز عبور قوی جایگزین کنید. `your_google_ai_api_key` را با کلید API معتبر خود جایگزین کنید.

4.  **اجرای سرور توسعه Next.js:**
    ```bash
    npm run dev
    # یا
    # yarn dev
    ```
    برنامه در آدرس `http://localhost:9002` (یا پورت دیگری که در `package.json` مشخص شده) قابل دسترس خواهد بود.

5.  **اجرای Genkit (اختیاری - برای توسعه و تست فلوهای AI):**
    اگر می‌خواهید فلوهای Genkit را به صورت جداگانه مشاهده و تست کنید، در یک ترمینال دیگر دستور زیر را اجرا کنید:
    ```bash
    npm run genkit:dev
    # یا برای حالت watch:
    # npm run genkit:watch
    ```
    این دستور Genkit Developer UI را در آدرس `http://localhost:4000` اجرا می‌کند.

### ورود به پنل مدیریت

*   به آدرس `/taupload` در مرورگر خود بروید.
*   **نام کاربری:** `admin`
*   **رمز عبور:** مقداری که در متغیر `ADMIN_PASSWORD` در فایل `.env.local` تنظیم کرده‌اید.

## ☁️ استقرار (Deployment)

این پروژه برای استقرار بر روی **Firebase App Hosting** پیکربندی شده است.

### پیش‌نیازهای استقرار

*   یک [پروژه Firebase](https://console.firebase.google.com/) ایجاد کنید.
*   [Firebase CLI](https://firebase.google.com/docs/cli) را نصب کنید و با حساب گوگل خود وارد شوید:
    ```bash
    npm install -g firebase-tools
    firebase login
    ```

### مراحل استقرار

1.  **اتصال پروژه محلی به پروژه Firebase:**
    اگر برای اولین بار است که پروژه را به Firebase متصل می‌کنید:
    ```bash
    firebase use --add
    ```
    سپس پروژه Firebase مورد نظر خود را از لیست انتخاب کنید.

2.  **فعال‌سازی App Hosting (در صورت نیاز):**
    اگر App Hosting برای پروژه Firebase شما فعال نیست، آن را از طریق کنسول Firebase یا با دستور زیر فعال کنید:
    ```bash
    firebase apphosting:backends:create
    ```
    و دستورالعمل‌های نمایش داده شده را دنبال کنید.

3.  **استقرار برنامه:**
    ```bash
    firebase deploy --only apphosting
    ```

4.  **تنظیم متغیرهای محیطی در Firebase:**
    *   **بسیار مهم:** پس از استقرار، باید متغیرهای محیطی (`ADMIN_PASSWORD` و `GOOGLE_API_KEY`) را در تنظیمات Backend سرویس App Hosting در کنسول Firebase خود تنظیم کنید. بدون این متغیرها، بخش مدیریت و قابلیت‌های هوش مصنوعی به درستی کار نخواهند کرد.
